LEO AI Chatbot — Phase 1 Demo

This is a plain HTML page (no React, no build step) that loads the LEO AI Chatbot SDK from a local build and initializes it. Open the browser console to see the backend health-check result. Click the Chat button in the bottom-right corner to open/close the placeholder panel.

Backend expected at http://localhost:4000 — start it with npm run build && npm start inside server/.
